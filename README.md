# 🌙 Light of Guidance - Islamic Dawah Hub

A beautiful, modern, and mobile-friendly Islamic website created to spread the light of guidance through authentic Islamic resources.

## ✨ Features

### 🎨 Design & Aesthetics
- **Minimal & Elegant**: Clean, modern design with Islamic geometric patterns
- **Dark/Light Mode**: Toggle between themes with smooth transitions
- **Arabic Typography**: Beautiful Amiri font for Arabic text
- **Mobile Responsive**: Optimized for all devices
- **Smooth Animations**: Engaging user experience with CSS animations

### 📚 Content Sections
- **Home Page**: Welcome message with featured Quran verse
- **Quran Section**: Authentic verses with Arabic text and translations
- **Hadith Section**: Authentic sayings of Prophet Muhammad (PBUH)
- **Islamic Tools**: Interactive tasbeeh counter, prayer times, daily duas
- **Resources**: Download sections for wallpapers, guides, and audio
- **About Page**: Mission statement and social media links

### 🛠️ Interactive Features
- **Tasbeeh Counter**: Digital dhikr counter with sound feedback
- **Daily Dua Generator**: Random authentic duas with sources
- **Prayer Times**: Display of daily prayer times
- **Theme Toggle**: Dark/light mode with localStorage persistence
- **Mobile Menu**: Responsive navigation for mobile devices
- **Smooth Scrolling**: Enhanced navigation experience

### 🚀 Technical Features
- **Fast Loading**: Optimized for performance
- **SEO Friendly**: Proper meta tags and semantic HTML
- **Accessibility**: Focus states and keyboard navigation
- **PWA Ready**: Service worker support for offline functionality
- **Cross Browser**: Compatible with all modern browsers
